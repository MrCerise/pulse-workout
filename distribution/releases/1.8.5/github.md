# Interval Coach 1.8.5

## English

This release prepares the current Interval Coach app for closed testing.

- Automatic version-tag uploads now target closed testing track `PreRelease Beta`, as a draft for review.
- Google Play uploads include localized release notes in English, French, German, Spanish and Italian.
- GitHub Releases include this curated changelog alongside the signed phone and Wear OS APK/AAB files, mappings and checksums.
- Missing, empty or oversized release notes are rejected before a release build starts.

The app includes the translations and fixes shipped in 1.8.4. This version changes release delivery and version metadata; it introduces no new workout behaviour.

## Français

Cette version prépare l’application Interval Coach actuelle pour les tests fermés.

- Les envois automatiques depuis les tags ciblent désormais la piste de tests fermés `PreRelease Beta`, sous forme de brouillon à vérifier.
- Les notes de version sont transmises à Google Play en anglais, français, allemand, espagnol et italien.
- La publication GitHub comprend ce journal des modifications, les APK/AAB signés pour téléphone et Wear OS, les fichiers de désobfuscation et les sommes de contrôle.
- Les notes manquantes, vides ou trop longues bloquent la publication avant la compilation.

L’application reprend les traductions et les correctifs de la version 1.8.4. Cette mise à jour concerne la publication et le numéro de version ; elle n’ajoute pas de nouveau comportement aux séances.
