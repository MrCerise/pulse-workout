# Interval Coach 1.8.7

## English

This release makes workouts shareable by QR code and redesigns the workout library and workout pages.

- Sharing a workout as a QR code works again. The old code held more data than a QR code can carry, so it never appeared; workouts are now encoded compactly and every bundled workout fits.
- Scan a workout code from **Workouts → + → Scan a QR code**, or import it from a screenshot or photo. You confirm before anything is added, and nothing is overwritten.
- Share the code as an image for chats and email.
- The library is split into favorites, your own workouts and the starter workouts. List and grid views scroll as one page, and every import lives under the + button.
- Workout pages show work and rest time and the structure as it was built — a block of eight rounds is one block marked ×8. Preview, share and schedule are one tap away, and duplicate and delete are in the menu.
- Eleven new starter workouts: E2MOM 16, Norwegian 4x4, Sprint Repeats, Jump Rope 30/30, Double Tabata, Lower-Body Burner, Core Crusher, Shadowboxing Combos, Morning Mobility, 4-7-8 Breathing and Deep Work 50/10.
- The phone now starts syncing with the watch on launch; before, the library and watch sessions did not reach the other device.
- Starter workout notes now show in the timeline.

## Français

Cette version permet de partager les séances par QR code et remanie la bibliothèque et la page des séances.

- Le partage d’une séance par QR code fonctionne à nouveau. L’ancien code contenait plus de données qu’un QR code ne peut en porter et ne s’affichait jamais ; les séances sont désormais encodées de façon compacte et toutes les séances fournies tiennent dans un code.
- Scannez un code depuis **Séances → + → Scanner un QR code**, ou importez-le depuis une capture d’écran ou une photo. Vous confirmez avant tout ajout, et rien n’est écrasé.
- Partagez le code en image pour vos discussions et e-mails.
- La bibliothèque est classée en favoris, vos séances et séances de départ. Les vues liste et grille défilent comme une seule page, et toutes les importations sont réunies sous le bouton +.
- La page d’une séance montre l’effort, la récupération et la structure telle qu’elle a été construite — un bloc de huit tours est un bloc marqué ×8. Aperçu, partage et planification sont à portée de main ; dupliquer et supprimer sont dans le menu.
- Onze nouvelles séances de départ : E2MOM 16, Norwegian 4x4, Sprint Repeats, Jump Rope 30/30, Double Tabata, Lower-Body Burner, Core Crusher, Shadowboxing Combos, Morning Mobility, 4-7-8 Breathing et Deep Work 50/10.
- Le téléphone lance la synchronisation avec la montre au démarrage ; auparavant, la bibliothèque et les séances de la montre n’arrivaient pas sur l’autre appareil.
- Les notes des séances de départ s’affichent dans le déroulé.
